# 미션 - 자판기

## 기능 구현 목록
1. 자판기가 보유하고 있는 금액 입력 및 검증
  - “자판기가 보유하고 있는 금액을 입력해 주세요.”
  - 예외 사항
    - 숫자가 아니면 예외 발생
      - “금액은 숫자여야 합니다.”
    - 10원 단위가 아니면 예외 발생
      - “금액은 10원 단위여야 합니다.”
2. 자판기가 보유한 동전 랜덤 생성 및 출력
3. 상품명과 가격, 수량 입력 및 검증
   - “상품명과 가격, 수량을 입력해 주세요.”
   - 예외 사항
     - 형식에 맞지 않으면 예외 발생
       - “입력 형식이 올바르지 않습니다.”
     - 상품명이 중복이면 예외 발생
         - “상품명이 중복입니다.”
     - 상품 가격이 100원 미만이면 예외 발생
       - “가격은 100원 이상이어야 합니다.”
     - 상품 가격이 10원 단위가 아니면 예외 발생
       - “가격은 10원 단위여야 합니다.”
4. 상품 재고 저장
5. 투입 금액 입력 및 검증
  - “투입 금액을 입력해 주세요.”
  - 예외 사항
    - 투입 금액이 숫자가 아니면 예외 발생
      - “금액은 숫자여야 합니다.”
    - 투입 금액이 10원 단위가 아니면 예외 발생
      - “금액은 10원 단위여야 합니다.”
6. 현재 투입 금액(남은 금액)으로 상품이 구매 가능한 상황인지 확인 후 잔돈을 돌려준다.
  - 확인 요소
    1. 현재 투입 금액(남은 금액)이 상품 최저 가격보다 적은지 확인
    2. 모든 상품이 소진되었는지 확인
7. 6번에서 구매 가능한 상황인 경우, 현재 투입 금액(남은 금액) 출력 후 구매할 상품명 입력 및 검증
   1. 현재 투입 금액(남은 금액) 출력
      - “투입 금액: %d원”
   2. 구매할 상품명 입력 및 검증
      - “구매할 상품명을 입력해 주세요.”
      - 예외 사항
        - 존재하지 않는 상품이면 예외 발생
          - “존재하지 않는 상품입니다.“
        - 재고가 없는 상품이면 예외 발생
          - “재고가 없는 상품입니다.”
   3. 현재 투입 금액(남은 금액) 및 재고 업데이트
   4. 6번 진행
8. 6번에서 더 이상 상품 구매 불가능한 상황인 경우, 현재 투입 금액(남은 금액) 및 잔돈 출력
   1. 현재 투입 금액(남은 금액) 출력
      - “투입 금액: %d원”
   2. 현재 보유한 최소 개수의 동전으로 돌려줄 잔돈 동전을 계산
