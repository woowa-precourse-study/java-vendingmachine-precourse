
### 자판기 보유 구매 입력
- [x] [ERROR] 금액은 숫자여야 합니다.
- [x] [ERROR] 금액은 10원으로 나누어떨어져야합니다.


## 자판기 동전 생성
- [x] 자판기가 보유하고 있는 금액으로 동전을 무작위로 생성한다.(투입 금액으로는 동전을 생성하지 않는다.)
- [x] Random 값 추출은 camp.nextstep.edu.missionutils.Randoms의 pickNumberInList()를 활용한다.

### 상품 입력
- [x] 상품명, 가격, 수량을 입력하여 상품을 추가할 수 있다.
- [x] [ERROR] 상품 가격은 최소 100원이어야합니다.
- [x] [ERROR] 금액은 10원으로 나누어떨어져야합니다.
- [x] [ERROR] 입력 형식이 올바르지 않습니다. - (상품명, 가격, 수량은 쉼표로, 개별 상품은 대괄호([])로 묶어 세미콜론(;)으로 구분한다.)
- [x] [ERROR] 금액은 숫자여야 합니다.

### 투입금액 입력
- [x] [ERROR] 금액은 숫자여야 합니다.

### 사용자 물건 구매 입력
- 사용자가 투입한 금액으로 상품을 구매할 수 있다.
- [x] [ERROR] 존재하지 않는 상품입니다.
- [x] [ERROR] 재고가 부족합니다.
- [x] --[ERROR] 금액이 부족합니다. → 이 경우 예외 말고 잔돈 바로 반환
- [x] 남은 금액이 상품의 최저 가격보다 적으면 바로 잔돈을 돌려준다.
- [x] 모든 상품이 소진된 경우 바로 잔돈을 돌려준다.

### 잔돈 반환
- [x] 현재 보유한 최소 개수의 동전으로 잔돈을 돌려준다.
- [x] 잔돈을 반환할 수 없는 경우 잔돈으로 반환할 수 있는 금액만 반환한다. (반환되지 않은 금액은 자판기에 남는다.)
- [x] 잔돈은 반환된 동전만 출력한다.

- [x] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException를 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 해당 부분부터 다시 입력을 받는다.
- [x] 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 [ERROR]로 시작해야 한다.
